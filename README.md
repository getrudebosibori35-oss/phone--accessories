# phone--accessories

Voltix Accessories is a React-based admin portal for a phone accessories store. It allows an administrator to view, search, add and update products.

## Features

- View products
- Search by product name and category
- Add new products
- Edit existing products
- Responsive interface
- Shared state using React Context
- Custom React hook
- Mock backend using JSON Server

## Technologies Used

- React
- JavaScript
- Vite
- React Router
- JSON Server
- CSS
- Vitest
- React Testing Library

## Setup

Clone the repository and install the dependencies.

```bash
npm install
```

Start the backend:

```bash
npm run server
```

Start the frontend in a separate terminal:

```bash
npm run dev
```

## Testing

Run the tests:

```bash
npm run test
```
